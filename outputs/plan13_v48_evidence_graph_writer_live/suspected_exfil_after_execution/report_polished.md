## 1. 事件结论与当前判断

经综合分析，研判本次事件为一起确认的高危安全事件，主要针对内网研发工作站 ws-rnd-04。该资产在分析窗口内表现出与“Suspected cloud-storage exfil chain”模式高度吻合的可疑行为，包括触发 JA4 指纹告警、与罕见存储主题域名建立可疑 TLS 通信、执行 PowerShell 脚本、压缩并外传大量数据。尽管存在部分背景流量和反证信号，但其强度不足以推翻主链。

当前判断如下：攻击者利用或仿冒云存储 API 通道作为命令与控制及数据外传的基础设施，将 ws-rnd-04 上的研发项目数据压缩后以加密方式上传至外部存储边界。目前证据不支持确认已观察到实现持久化、横向移动或对更多内部资产的广泛控制。

事件时间线围绕 ws-rnd-04 的一系列可疑行为展开，所有事件均在 2026-06-03 的 UTC 时间窗口内被观测到。最早的可疑信号是 2026-06-03 16:28:00 UTC，ws-rnd-04 解析了罕见存储主题域名 files-sync-share.net，随后在 2026-06-03 16:34:20 UTC 与该域名的 IP 198.51.100.144 建立了一次较短的可疑 TLS 会话，这被视为后续大规模数据外传的前置通信。

## 3. 关键证据判断

当前结论的核心支撑在于 ws-rnd-04 上观察到的一条逻辑自洽且时序紧密的可疑行为链，并非孤立告警。种子告警不仅提供了“Suspected cloud-storage exfil chain”的家族提示，更重要的是告警本身匹配了高度特定的 JA4 TLS 指纹，这使得连接行为从普通的加密流量中凸显出来，具有明确的恶意信标特征。随后，该告警与短时间内的一系列主机侧行为--PowerShell 脚本执行、项目文件压缩打包、文件重命名伪装、以及最终指向同一存储设施的大流量加密上传--构成了完整的上下文闭环。特别是 DLP 记录显示外传数据经过加密且无法检查内容，这与用于规避检测的外传手法相符，而后续解析姊妹域名 api.files-sync-share.net 并建立后续会话的行为，进一步强化了其作为 C2 通道的判断。

然而，必须明确当前证据所能支撑的结论边界。尽管确认了可疑执行脚本（sync.ps1）的存在和压缩外传行为，但由于 EDR 未能保留完整的 PowerShell 命令行，暂存脚本的具体内容和行为无法完全还原。因此，当前结论聚焦于“利用云存储通道进行数据外传”这一事实，而无法就攻击者是否通过该脚本实现了完整的系统控制、凭证窃取或持久化驻留等更强结论做出判断。缺失的执行细节是当前研判的明确边界。
