## 2. 事件过程与关键时间线

种子告警及其后短时间内两次连续重连，是支持 ws-legal-03 存在可疑信标行为的主要依据。这三次 TLS 会话共享相同的 JA4 指纹和目的地端点，形成了时间上高度聚集、行为上具有重复模式的网络信号序列，符合 command-and-control beacon 的典型流量轮廓。来自被动基础设施上下文的外部信息也确认，该 IP 198.51.100.131 在同一周内托管了多个不同客户域名，但这一事实本身既能解释为共享托管平台被滥用于 C2 信道，也能单纯解释为正常共享基础设施上的多租户活动。

当前主链主张的可信度受到两个已闭合缺口的支撑：其一，围绕种子告警已补足最小上下文，明确了源资产、目的端点、JA4 指纹和时间范围；其二，显式反证检查已完成，检索到了可解释为维护、更新或正常基线的事件。这些反证事件并未能推翻主链上的可疑信标模式--ws-legal-03 在同一时间窗内确实存在经批准的 SSO 浏览器扩展更新和正常 Microsoft 身份认证流量，但同样无法直接解释为何该资产在约九分钟内反复与一个罕见队列主题域名建立加密信道。

更关键的约束在于未闭合缺口。主机侧执行缺口直接限制了结论的强度：资产 ws-legal-03 在相关时间窗内缺乏命令行遥测，无法确认是否存在恶意进程启动、脚本执行、持久化机制或横向移动行为。因此，当前只能确认可疑网络信标的发生，不能确认攻击者控制、恶意软件完整执行链、持久化或横向移动闭环。关联资产复核缺口和显式扩线缺口则限制了影响范围的判断--ws-legal-09 和 ws-legal-12 的信号虽出现在同一共享 IP 上，但尚无独立验证，且未围绕当前 关键关联指标 执行更大时间窗的复现搜索，无法确认是否存在更广泛的影响。
