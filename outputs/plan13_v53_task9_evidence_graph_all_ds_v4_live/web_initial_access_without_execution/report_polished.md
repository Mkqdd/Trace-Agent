# 3. 关键证据判断

确认当前结论的核心在于以下几点紧密耦合的证据：web-app-02 在极短时间窗口内先后经历了两波明确的管理门户漏洞利用，紧接着就在同一源 IP 10.61.2.20 上解析并连接了 auth-edge-panel.net，并且该连接被专门规则命中为可疑 web beacon。这不仅构成了“利用-解析-信标”的逻辑链条，而且在时间上呈现高度集中的特征--从首次利用到种子告警仅隔 12 分钟，后续复连又发生在 4 分钟之后。这一时序紧密度很难用正常的业务调度或随机访问来解释。更关键的是，种子告警所依赖的 JA4 指纹是一种对 TLS 客户端特征的稳定描述，命中的指纹值在主支撑事件中被明确记录，与已确认的对象角色事实（fact-object-obj-06）直接匹配，支撑了“同一客户端或工具链”的判断。因此，我们可以确认 web-app-02 至少经历了可疑的外联行为，且该行为与先行漏洞利用高度关联，足以交付“可疑事件簇”级别的结论。
