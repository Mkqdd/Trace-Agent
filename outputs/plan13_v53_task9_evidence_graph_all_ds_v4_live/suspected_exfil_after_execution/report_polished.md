## 1. 事件结论与当前判断

本次事件是一起围绕种子告警“Suspected cloud-storage exfil chain”形成的确认外传事件，不再停留在单点异常层面。种子资产 ws-rnd-04 在 2026-06-03 16:40:00 UTC 由 JA4 指纹 t13d190900_44ac2200b3c1_ab11cd22ee44 触发了针对 files-sync-share.net（198.51.100.144）的可疑 TLS beacon，随后在数十分钟内出现压缩打包、文件暂存和大体积上传的连续动作序列，构成了明确的数据外传证据链。当前证据足以交付事件级结论，但未包含攻击者初始入口、持久化、横向移动或外传后利用的完整闭环。

在证据簇中，还引出了 ws-rnd-09、ws-rnd-12 等资产的候选关联事件，其中部分信号可被备份作业、SharePoint 正常同步及共享 CDN 访问等背景或替代解释覆盖，目前不能将其纳入已确认受影响范围。因此，事件当前的确定性结论仅限于 ws-rnd-04 上的外传执行链，更广泛的组织内扩散、攻击者控制和归因需要下一步独立验证后判定。

## 2. 事件过程与关键时间线

在 2026-06-03 16:28:00 UTC，ws-rnd-04 首次解析了稀有存储主题域名 files-sync-share.net，作为种子告警前的 DNS 解析线索出现。之后，该资产在 2026-06-03 16:34:20 UTC 与 files-sync-share.net（198.51.100.144）建立了短暂 TLS 会话，形成了外传前的探测或信令特征。2026-06-03 16:40:00 UTC，同一工作站再次通过 files-sync-share.net 发起 TLS 通信并被 JA4 指纹告警命中，告警类型为可疑 C2 beacon，构成本次事件的核心确认起点。

## 3. 关键证据判断

当前结论能够成立，是因为主证据链给出了一组在时间、空间和行为上高度闭合的执行与外传序列，而非仅依赖单个告警命中。ws-rnd-04 上围绕 files-sync-share.net 和 api.files-sync-share.net 的同 IP 通信与 JA4 指纹形成固定模式，在种子告警前后相继发生 DNS 解析、TLS 短会话、PowerShell 暂存脚本执行、7z.exe 打包和约 640 MB 的加密上传，且 DLP 虽无法解包但仍提供了传输体量佐证。这一连串动作符合“云存储外传链”的家族提示，且在时间线上衔接紧密，很难被完全归因于用户误操作或软件自主更新。

与此同时，insufficient_evidence_limits 限制我们必须明确：尚不具备持久化、横向移动、远程加载器或多资产指令级控制证据链，因此不能将结论拔高为“已观察到控制 ws-rnd-04 并渗透至研发网段”。EDR 未能保留完整的 PowerShell 命令行，使暂存脚本内容未能完整重构，这也是阻止该事件从外传链扩展到完整攻击链的核心缺口。目前仅能确认外传执行链本身，而非攻击者持续控制或横向闭环。

## 4. 影响范围、候选对象与外部基础设施

当前纳入确认受影响范围的资产是 ws-rnd-04，该工作站出现了暂存脚本执行、文件打包及向外部基础设施的大体积上传，需要进入隔离和取证流程。作为候选资产，ws-rnd-09 因单次访问同一存储边缘且伴随已批准备份作业，其真正受影响情况需要独立验证；ws-rnd-12 对相同 IP 的访问走的是不同 CDN 域名，更有可能是共享基础设施背景流量，目前不应写入受影响范围。
