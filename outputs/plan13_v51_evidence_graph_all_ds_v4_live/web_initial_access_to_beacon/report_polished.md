## 3. 关键证据判断

当前结论成立的核心在于一条连续且时序高度自洽的证据链。从 14:02:00 UTC 的漏洞利用请求开始，web-app-01 在 5 分钟内解析了异常域名 cdn-auth-check.net，并在 10 分钟内与外部 IP 198.51.100.88 建立了命中特定 JA4 指纹的 TLS 信标，这三步构成了清晰的 Web 初始入侵到命令与控制的行为序列。随后在主机上发现的 webshell 文件 shell.aspx、PowerShell 启动器执行以及凭据存储访问，为攻击者获得了代码执行能力和凭据窃取意图提供了主机侧佐证，也将事件从单点网络告警推进为已确认的主机失陷。这些事实的时间顺序、逻辑关联和技术特征互相印证，使得“确认安全事件”的结论具有高置信度。
